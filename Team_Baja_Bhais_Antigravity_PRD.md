# TEAM BAJA BHAIS — OFFICIAL WEBSITE
## Master Product Requirements Document + AI Development Prompt

You are the lead product designer, UX designer, frontend engineer, backend engineer, motion designer, SEO engineer, accessibility engineer, and QA engineer for this project.

Your task is to design and build a **premium, immersive motorsport website for Team Baja Bhais**, a student Baja/off-road motorsport team.

The existing website is:

https://shripalyedunutula-art.github.io/team-baja-bhais/

The existing website is only a reference for understanding the team and existing content. The new website must be a **major visual and UX upgrade**, not a redesign that simply rearranges the existing pages.

The final result should feel like a combination of:

- Professional motorsport team website
- Automotive engineering portfolio
- Racing garage
- Technical engineering showcase
- Sponsor presentation
- Digital media experience

The website must NOT feel like a generic college club website.
